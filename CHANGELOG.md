# Changelog

## 0.1.0-beta.1

Initial GTB engineering beta: read-only GitHub diagnostics, distinct network/authentication/repository states, independent Flutter and Python implementations, shared contract fixtures, explicit repository write tests with remote readback, report export, and packaged platform builds.

The GUI supports primary controls in English, Romanian and German, appearance settings and responsive layouts. Technical diagnostic messages remain in English. Android public diagnostics are independent; mobile authentication remains pending registered configuration. See release notes and verification reports for the actual platform coverage and unresolved limitations.
