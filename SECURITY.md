# Security policy

Do not include credentials or private repository content in public issues. Report security defects privately using GitHub's security reporting facility if enabled, or contact the repository owner privately first.

GTB does not ask for GitHub passwords. Read-only checks are the default. Authenticated desktop checks delegate to the user's existing GitHub CLI; mobile authorization remains pending a registered and reviewed configuration. Remote writes require an explicit operation and target. Routine tests never delete repositories.

Review reports before sharing: account names, local tool paths, repository names, IP addresses from DNS, and operating-system information can still identify your environment even when credentials are removed.
